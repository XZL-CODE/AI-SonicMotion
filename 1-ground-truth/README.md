# Ground Truth · 落地

深夜 R&B / neo-soul，英文演唱，配中文字幕。一次夜航：从跑道起飞，穿过云层，在云上的日落里盘旋，再穿云下降，落回城市的灯火里。

> 云层之上，答案都很轻；没有落地，就不算真的。

## 简介

飞得再高，也要落地。这首歌写"向上"和"落地"之间的张力：云层之上，答案唾手可得，却轻得没有分量；只有落回地面、经得起检验的，才算数。歌名 *Ground Truth* 既是"地面上的真相"，也取"经过验证的事实"之意。画面跟着这趟夜航走，节拍点亮跑道和城市的灯，唱到的词在画面里逐个落下。

## 写这首歌的时候

作者习惯不轻信任何没经过验证的答案，却常常放过自己那些停在纸面上的计划。答案越来越容易得到，方案一夜就能写完，路线图画得完整漂亮，可写得像做完了，不等于真的做完；想清楚了，世界也不会因此配合。

这首歌写给那段在云上一圈圈盘旋的日子：用对待答案的标准对待自己，把它带下来，交到真实的地面上，被使用、被检验，哪怕颠簸，它才有了重量。仰望只是一半，落地是另一半。所以歌的最后，人站在跑道上，依然抬头望天。

python3 engine/music/analyze.py 1-ground-truth 1-ground-truth/outputs/takes/take_7_b.wav
