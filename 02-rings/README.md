# More Rings Than Years · 年轮

有机 drum & bass，融合室内民谣与慢燃独立摇滚，英文演唱，配中文字幕。一棵在风里长大的树：外面看，它只是安静地站着；截开来，年轮比它的年纪还多。

> 有些年，你得长大两次。

## 简介

熬过旱季的树，会多长出一圈"伪年轮"：生长在干旱里停下，等雨来了又接着长，一年长出两圈。所以有的树，年轮比它的年纪还多。这首歌写的是这样一种沉稳：它来得早，是一圈一圈扛出来的，外面看却只是安静地站着。别人说它懂事、坚强，很少有人坐下来数一数那些年轮，看清每一圈的代价。画面从山坡上的一棵树开始，潜进土里去看它找水的根，再切开树干，让节拍一圈圈点亮年轮。

## 写这首歌的时候

有一种夸奖，有的人很早就听惯了：懂事，成熟，比同龄人稳。说的人点点头就走开了，很少有人问这份稳是怎么来的。它往往来自几段不得不早点长大的日子：事情不按预想的走，付出也不一定马上有回应，只能在条件有限的时候自己想办法，一边扛着，一边不让情绪耽误手上的事。

这首歌想做那个愿意坐下来数年轮的人：不只说一句"你真坚强"，而是看清每一圈是怎么长出来的，又付出了什么。所以歌的最后没有结论，只说那棵树还在长。

## 基本信息

|---|---|
| 风格由来 | 同一段副歌试了三个方向：木质民谣、慢燃摇滚、liquid drum & bass；最后把三者融成第四版（样例 D） |
| 风格 | 有机 drum & bass：指弹木吉他、大提琴、钢琴固定音型、层层叠上去的弦乐，底下是滚动的碎拍与超低音，女声半速慢唱。第一段主歌只留民谣那几层，到副歌碎拍和超低音才从底下涌上来；桥段退回吉他、大提琴和人声 |

## 封面

`covers/` 里是为这首歌画的发布封面，手写 SVG，导出为 JPG（导出命令见[仓库 README](../README.md)）。画面取自副歌的树干截面：被数到的那一圈发着金光，两点小光绕着它走，几圈淡金的是伪年轮。B 站封面截面在右、文字在左；公众号封面把树芯放在画面下方之外，年轮拱成弧，金色那圈从标题上方跨过。文字为歌名、"AI 原创 · 民谣 × Drum & Bass"与副歌句。

| 文件 | 用途 |
|---|---|
| `bilibili.svg` → `bilibili.jpg` | B 站，16:9，1920×1080；文字在中间 4:3 内，底部两角留给角标 |
| `wechat.svg` → `wechat.jpg` | 公众号头条，2.35:1，1410×600；信息都在中间 600×600 |
| `wechat-square.jpg` | 公众号中间 600×600，用于 1:1 转发卡片与次条封面 |

## 文件

| 文件 | 内容 |
|---|---|
| `song.json` | 风格描述、生成参数、音色参考、分段歌词（英文 + 中文译文、`hook` 标记）、每段的画面场景与章节标题 |
| `scenes.py` | 本曲各段画面：山坡孤树、潜入地下的根、一动不动的树干特写、年轮截面（含伪年轮与径向裂纹）、旱季树冠、数年轮、四季年轮、日出，以及随节拍生长的根与枝、底鼓推着往上走的水光、军鼓荡开的年轮涟漪等 |
| `timbre-reference.mp3` | 音色参考：选定的样例 D（三种风格融合，约 60 秒） |
| `composition-take11.json` | 选定的作曲：take 11 的模型规划与音频编码 |
| `covers/` | 发布封面（见上节） |

## 重新生成

```bash
python3 engine/music/generate.py 02-rings --seeds 11 --codes 02-rings/composition-take11.json
python3 engine/music/analyze.py 02-rings 02-rings/outputs/takes/take_11.wav
python3 engine/video/render.py 02-rings 02-rings/outputs/analysis/take_11.json
```

在仓库根目录运行。音频、分析与视频输出在 `outputs/`（不入库）。环境准备见[仓库 README](../README.md)。
