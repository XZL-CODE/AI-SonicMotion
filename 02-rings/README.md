# More Rings Than Years · 年轮

木质民谣与慢燃摇滚的融合，英文演唱，配中文字幕。一棵树的一生：从夜里落下的一粒种子，到山坡上的风、地下找水的根、暴风雨、旱季、风雪和春天。

> 有些年，你得长两次。

## 简介

熬过旱季的树，会多长出一圈"伪年轮"：生长在干旱里停下，等雨来了又接着长，一年长出两圈。所以有的树，年轮比它的年纪还多。这首歌写一棵站在风口上的树：它总是安静地站着，用的力都长进了年轮里，没人看见；直到有人愿意留下来，一圈一圈数清楚。MV 跟着这棵树从一粒种子长起，画面一角记着年份和年轮数，到最后，年轮比年份多。

## 写这首歌的时候

见过一张树木截面的照片：大多数年轮宽宽窄窄地排着，中间有两圈挨得特别近，像是同一年里长了两次。后来才知道那是一个旱年：雨迟迟不来，树停下了，等雨来了又接着长。树不会说话，可它经历过什么，年轮都记着。

这首歌写给那些安静站着的东西。站得稳，不等于不费力，只是费的那些力都长进了里面。所以歌里那个人做的事很简单：留下来，陪它把年轮一圈一圈数清楚。

## 段落与画面

MV 跟着一棵树过完它的二十五年，画面全用光来画：山脊是发光的轮廓线，地面上绕着树一圈圈光环，每小节从树脚再荡开一圈；树由光丝和光点组成，每个底鼓都有一道光从树根爬到枝梢。每段一套配色。画面右上角记着年份和年轮数；暴风雨、旱季、风雪和春天里，树旁浮着一小块年轮截面，每长出一圈就亮一下，伪年轮泛着淡金。

## 封面

`covers/` 里是为这首歌画的发布封面，手写 SVG，导出为 JPG（导出命令见[仓库 README](../README.md)）。画面取自树干的截面：被数到的那一圈发着金光，两点小光绕着它走，几圈淡金的是伪年轮。B 站封面截面在右、文字在左；公众号封面把树芯放在画面下方之外，年轮拱成弧，金色那圈从标题上方跨过。文字为歌名、"AI 原创 · 民谣 × 慢燃摇滚"与副歌句。

| 文件 | 用途 |
|---|---|
| `bilibili.svg` → `bilibili.jpg` | B 站，16:9，1920×1080；文字在中间 4:3 内，底部两角留给角标 |
| `wechat.svg` → `wechat.jpg` | 公众号头条，2.35:1，1410×600；信息都在中间 600×600 |

## 重新生成

```bash
python3 engine/music/generate.py 02-rings --seeds 7 --codes 02-rings/composition-take7.json
python3 engine/music/analyze.py 02-rings 02-rings/outputs/takes/take_7.wav
python3 engine/video/render.py 02-rings 02-rings/outputs/analysis/take_7.json
```

在仓库根目录运行。音频、分析与视频输出在 `outputs/`（不入库）。环境准备见[仓库 README](../README.md)。
